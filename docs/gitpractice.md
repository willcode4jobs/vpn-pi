GIT WORKFLOW

GIT PREFIXES
1a. feat/  New feature work. This will be for major changes, and added rulesets for the scope of this project.
1b. feat: commit message
2a. fix/  Bug fixes
2b. fix: commit message
3a. chore/  Maintenance, configurations, dependency work
3b. chore: commit message
4a. refactor/  Refactoring existing code
4b. refax: commit message
5. docs/  Documentation updating/uploading
5b. dox: commit message
6a. test/  automated tests
6b. test: commit message
A = Branch Name
B = Commit Message Prefix

GIT RULES
Typically, all commit messages are lower case with minimal punctuation, easier to read.
Commit messages don’t have to be perfect, but they have to be descriptive.
Prefixes must be used at start of commit message to signal what they are.
