## What happened, in order

1. **Bug:** files uploaded through the GUI always read as the hub (`vega`). Cause:
   the frontend never sends an uploader, so the backend fell back to its own
   `GUI_NODE_NAME` — and one backend on the hub serves everyone. Diagnosed and
   confirmed against the code (`main.py`, `mock.py`).
2. **Fix = wg0-address allowlist** (`app/peers.py`): a request's wg0 source
   address (cryptographically pinned by WireGuard) is matched to an allowlist —
   that both authenticates and names the adder. Stored the **raw IP**, no name
   translation (William's call — always available, no map to keep in sync as
   nodes like arcturus come online). Allowlist `10.42.0.1–.7`. Deployed to vega.
3. **Reframed the "IDS alert layer":** it was *not* done — it was mock
   (`MockDataSource`), and the daemon source had been cut. Chose to build it for
   real, multi-node, on the master (professor's scope).
4. **Planned the IDS mesh** as a deliberate doc set before code. Chose **hub
   blind-relay, E2E to the master** over a plaintext hub collector — the only
   option that honors "security data stays off the edge" given spoke↔spoke is
   dead and the hub is the only universal rendezvous.
5. **Built Steps 1–3** (de-risked order, each committed + tested):
   `baec342` HostDataSource + `GUI_IDS` factory; `1d35651` envelope + registry +

## Decisions & rationale

- **IDS scope = host events only.** Sources are `USB / LOGIN / AUTH / REBOOT`
  (udev / auditd / fail2ban / boots) — the model encodes this. The daemon's
  dead-tunnel/mesh-health alerts are **deliberately not** in the mesh view: the
  daemon status-socket coupling was cut, and re-introducing it is out of scope.
  If wanted later, the daemon can ship its **own signed alerts through the same
  blind relay** as just another source — a clean extension, not a v1 need. This
  is now a recorded choice, not a leftover of cutting the source.
- **Topology = hub-and-spoke, settled. Both polaris and vega are load-bearing.**
  polaris = master/aggregator (out of the data path), vega = hub + blind relay.
  This answers the still-open "master may be unnecessary / leaning P2P" question
  by fiat — defensible because spoke↔spoke is dead and hub-and-spoke is what works
  today. **A P2P pivot would gut this design** (no blind relay, no master-pull) —
  the same pivot that moved the file authority. If the external `PROJECT_CONTEXT`
  doc still lists topology as open, mark it settled there too.
- **Attribution from the verified Ed25519 signature only**, never the
  hub-visible plaintext `node` field — held as an invariant for Steps 4–5.
- **Sequence numbers do double duty** — replay dedupe `(node, seq)` *and*
  suppression/gap detection — one mechanism, by design.
